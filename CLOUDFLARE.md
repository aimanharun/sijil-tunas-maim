# Cloudflare Pages

Projek ini ialah aplikasi statik React + Vite. Tetapan Cloudflare Pages:

- Build command: `npm run build`
- Build output directory: `dist`
- Node.js: 20 atau lebih baharu

Jika anda memuat naik fail binaan terus tanpa sambungan Git, muat naik kandungan folder `dist` melalui Direct Upload. Fail Excel diproses dalam pelayar dan tidak disimpan pada Cloudflare. Selepas halaman dimuat semula, data peserta yang dimuat naik perlu dimasukkan semula.
